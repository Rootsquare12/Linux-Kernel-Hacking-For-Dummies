# Chapter 4. 커널 보호 기법 2 - KASLR과 그 우회

운영체제는 소프트웨어이므로, 메모리에 적재되면 가상 주소를 부여받습니다. 만약 해커가 커널이 적재된 주소 위치를 예측할 수 있다면  익스플로잇을 너무나도 쉽게 할 수 있을 것입니다. 이를 예방하기 위해 개발자들은 커널이 부팅할 때마다 메모리에 적재되는 위치를 변경하기로 했습니다. 이번 장에서는 두 번째 보호 기법인 KASLR(Kernel-Address Space Layout Randomization)을 설명합니다. 이 방패를 우회하기 위해 커널 내 정보를 유출하는 법을 배웁니다.

- 4-1. 운영체제의 메모리 관리, x86-64 에서의 메모리
- 4-2. 리눅스 커널은 메모리의 어디에 적재될까?
- 4-3. 보호 기법 : KASLR 이란 무엇인가요?
- 4-4. KASLR 우회하기 : 커널 정보 유출(Information Leak)
